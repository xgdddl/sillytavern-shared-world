# 后续工作

1.0.0-rc.1 已补齐：

1. 各自 GitHub 身份和读写检查、不分发管理密钥、本机加密凭据。
2. 真实 GitHub 网络双客户端并发与重连读回；不同账号协议使用 HTTP 测试服务验证。
3. 新人物、物品、别名引用、物品数量和状态提取；依据检查。
4. 全局未来节点、独占事实因果链、现场候选的一致确认与冲突保留。
5. 跨设备账号恢复、设备控制转移、外置世界书版本识别。
6. 存档分片、导入副本、长期摘要、失败重提取与手机宽度界面。

发布候选尚需验收和可能的后续演进：

- 多名真人、不同真实账号、手机真机和长篇剧情持续游玩。
- 实际模型与预设组合的提取准确率，隐含矛盾、同义表达和复杂地点别称。
- 更便捷的 GitHub App/OAuth 授权；本版使用本人已有凭据，不声称免账号加入。
- 高频大世界的服务限流与性能；当前 GitHub 不提供即时推送体验。
- 其他现成数据服务、群聊及更多第三方扩展组合。

本项目保持无游戏房主、各自正文决定叙事、既有事实可追溯、冲突保留原文的原则。代码安装与云端世界数据配置相互独立。
