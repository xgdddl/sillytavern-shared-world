# 1.0.0-rc.2

- 增加自定义酒馆流式接口的资料生成适配，不改动用户的全局接口配置。
- 额外接口支持选择流式，处理 SSE 分帧、中文跨字节、推理字段隔离、流内错误及普通 JSON 回退。
- 增加四项流式协议检查。禁用生成的上游服务仍需使用者启用或更换接口，不伪报模型验收成功。
- 保存各世界、各人物的独立进度，切换后返回或重新选择人物时恢复进度。

# 1.0.0-rc.1

- 补齐共同开场、全局未来节点、持续世界事实和独占事实交接。
- 新人物和物品提取、别名引用、数量/损坏/消耗，逐字原文依据检查。
- 现场结果候选：一致后原子确认双方经历，冲突保留双方；未提交方超时仍受托管范围限制。
- 背景退出与托管退出分开执行；设备租约和主动控制转移。
- 本人 GitHub 身份、连接写读测试、跨设备邀请、本机身份文件、加密凭据。
- 正文草稿编辑重提取、导出恢复副本、持久长期摘要与自动整理。
- 大存档分片、完整性校验和条件缓存，年表分页。
- 外置世界书参与卡版本识别，聊天切换和后台生成保护。
- 新写入采用 shared-world/2，继续读取旧版记录；旧客户端应更新后参与。

这是一份功能候选。已知外部边界与验收范围见 README 和连接说明，不将模拟协议测试描述成真实多人长期游玩。
